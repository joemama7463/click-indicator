# Click Indicator

Geode mod that shows your inputs on screen while playing a level.

- Tapered track with a baseline and side chevrons that turn green while you hold
- Each click spawns a note (green while held, orange after release) that scrolls up
- Green PERFECT text above the track and a small one that floats up from your icon
- No sound effects
- Settings: enable, scale, opacity, scroll speed, both PERFECT texts, X/Y position

## Build (easiest: GitHub)
1. Push this folder to a GitHub repo.
2. The Actions tab runs the build automatically.
3. Download "Build Output", grab the `.geode` file, drop it in your GD `geode/mods` folder.

## Build (local)
1. Install the Geode SDK + CLI: https://docs.geode-sdk.org
2. `geode build`

Targets Geode v5.11.2 / Geometry Dash 2.2081 (Windows, Mac, iOS, Android).
